# ИИ-консультант «Тюльпановый сад» в чате

## Что увидит покупатель
- Круглая кнопка с иконкой-тюльпаном в правом нижнем углу на всех страницах сайта (кроме админки). Переключатель темы остаётся слева.
- По нажатию открывается окно чата. Сначала короткая форма: имя, телефон, галочка «Согласен с политикой конфиденциальности» (ссылка на страницу политики). Без галочки начать нельзя.
- Дальше — чат с ИИ-флористом. Он:
  - знает только реальные товары из каталога (названия, цены, наличие, состав);
  - помогает подобрать готовый букет под повод, бюджет и цвет;
  - собирает свой букет из тюльпанов поштучно и подарков, считает итоговую сумму;
  - когда покупатель согласен — уточняет дату, время, адрес и текст открытки, показывает итог и после подтверждения оформляет заявку (она появляется в «Заявках» как обычный заказ);
  - если не может помочь или покупатель просит человека — зовёт оператора и создаёт обращение.
- Разговор сохраняется: если закрыть окно или перезагрузить страницу, переписка остаётся (в этом браузере).
- Когда оператор подключился, его ответы появляются в том же окне с пометкой «Оператор», ИИ в этот момент молчит.

## Что увидит магазин в админке
Новый раздел «Чаты» (для администратора и сотрудника):
- список всех разговоров: имя, телефон, дата, последнее сообщение, метка «Нужен оператор» и «Оформлен заказ»;
- фильтр «Все / Нужен оператор / Закрытые»;
- открыв чат, видно всю переписку, можно ответить покупателю от имени оператора, закрыть обращение или вернуть чат ИИ;
- счётчик новых обращений рядом с пунктом меню.

## Технические детали
- База: таблицы `chat_sessions` (имя, телефон, согласие+время, статус `ai|operator|closed`, `needs_operator`, `order_id`, секретный токен посетителя) и `chat_messages` (роль `user|assistant|operator`, содержимое). RLS: читать/писать могут только admin/staff; посетитель работает только через серверные функции по токену сессии (хранится в localStorage).
- Серверный маршрут `/api/chat`: проверяет токен, загружает историю из базы, вызывает Lovable AI (`openai/gpt-6-astra`, Responses API, стриминг) с инструментами:
  - `search_products` — поиск по каталогу из базы;
  - `calculate_bouquet` — расчёт суммы по реальным ценам;
  - `create_order` — оформление заявки (та же логика, что в корзине; только после явного подтверждения);
  - `request_operator` — пометить чат и передать оператору.
  Сообщения сохраняются в `onFinish`. Если статус `operator` — ИИ не отвечает.
- Ответы оператора: админка пишет в `chat_messages`, окно покупателя опрашивает новые сообщения раз в несколько секунд.
- UI чата на компонентах AI Elements (разговор, сообщения с markdown, поле ввода, «Думаю…»); ответы ИИ без фона, сообщения покупателя — в розовом «пузыре» с контрастным текстом.
- Ошибки ИИ (лимит, кредиты) показываются в окне понятным текстом.
- Проверка: сборка, Playwright — анкета, подбор букета, расчёт, оформление заявки, вызов оператора, ответ из админки.
